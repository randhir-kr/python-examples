# python-examples

A collection of Python examples demonstrating pythonic code patterns, built-in data structures, and best practices.

## Project Structure

### 📚 [built-in-data-structures/](built-in-data-structures/)
Examples of Python's core data structures and their usage:

- **[dictionary.py](built-in-data-structures/dictionary.py)** — Dictionary operations, key-value pairs, and manipulation
- **[lists.py](built-in-data-structures/lists.py)** — List methods, indexing, slicing, and iteration
- **[sets.py](built-in-data-structures/sets.py)** — Set operations, uniqueness, and membership testing
- **[tuples.py](built-in-data-structures/tuples.py)** — Tuple creation, unpacking, and immutability

### 🔄 [comprehensions/](comprehensions/)
Pythonic ways to create and transform collections:

- **[dictionary_normal.py](comprehensions/dictionary_normal.py)** — Traditional dictionary creation with loops
- **[dictionary_pythonic.py](comprehensions/dictionary_pythonic.py)** — Dictionary comprehensions
- **[list_normal.py](comprehensions/list_normal.py)** — Traditional list creation with loops
- **[list_pythonic.py](comprehensions/list_pythonic.py)** — List comprehensions
- **[set_normal.py](comprehensions/set_normal.py)** — Traditional set creation with loops
- **[set_pythonic.py](comprehensions/set_pythonic.py)** — Set comprehensions

### ✨ [pythonic/](pythonic/)
Idiomatic Python patterns and techniques:

- **[list_iteration_with_indices_non-pythonic.py](pythonic/list_iteration_with_indices_non-pythonic.py)** — Using index-based loops
- **[list_iteration_with_indices.py](pythonic/list_iteration_with_indices.py)** — Pythonic enumeration with `enumerate()`
- **[variable_swap_non-pythonic.py](pythonic/variable_swap_non-pythonic.py)** — Traditional variable swapping with a temporary variable
- **[variable_swap.py](pythonic/variable_swap.py)** — Pythonic tuple unpacking for variable swapping

## Key Concepts

Each example contrasts **non-pythonic** (traditional) approaches with **pythonic** (idiomatic) Python solutions, helping you write cleaner, more readable, and more efficient code.

## Getting Started

Run any example file with:
```bash
python3 filename.py
```

For example:
```bash
python3 built-in-data-structures/dictionary.py
python3 comprehensions/list_pythonic.py
python3 pythonic/variable_swap.py
```
